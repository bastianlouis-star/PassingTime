# Passing Time: project state

Written so the project can be picked up on another computer. Last updated 2026-10-14.

## What it is

An immortal character, alone, passing time. Small pastimes (reading, chess, films) run out and he must find longer
ones, up to civilisations, species, a planet, the death of the universe, and letting his own atoms go. It began as a
2D pixel prototype (archived), moved to Godot 4.4, and is now HD-2D: procedural 3D dioramas, a painted pixel hero
billboard, and a post-processing shader. Everything (art, music, sound) is generated by code at runtime.

## Getting going on a new machine

1. Install **Godot 4.4.1 stable** (standard, not .NET). The Compatibility renderer is used.
2. Open `godot/project.godot` and press F5, or run headless checks (below).
3. For the Windows exe you need the 4.4.1 export templates (editor: Editor > Manage Export Templates), then
   `godot --headless --path godot --export-release "Windows Desktop" ../PassingTime.exe`.
   The icon is applied with `rcedit-x64.exe`; `godot/export_presets.cfg` expects it (see the README). If you do not
   have it, switch `application/modify_resources` off in that preset.
4. The progression graph: `godot --headless --path godot --script tools/export_graph.gd` writes
   `docs/progression.json`, then `python tools/make_graph.py` writes `docs/progression.svg`. The PNG was rendered
   from the SVG with headless Chrome (`chrome --headless --hide-scrollbars --window-size=1508,<svg height>
   --screenshot=docs/progression.png file:///.../docs/progression.svg`). Godot's own SVG rasteriser drops text, so
   do not use it for this.

Saves go to `user://passing_time.json` (Godot's app-data folder). Delete it to start over; the test scripts do not
write it (`shot_args = {"nosave": "1"}`).

## Design rules that have been settled

- No bars, no key, no boredom system. HUD: floating text-only action menu above the thing you stand at,
  subtitles at the bottom, era title top-left, game clock top-right. Real play time is shown only on the farewell
  screen (Esc) and the final screen.
- No fast-forward. Time-lapses play in real time; each action has a real-seconds length (`sec`) and a game duration.
- Discovery-driven. Locked actions are hidden. Exits (the way to the next era) are always listed and answer for
  themselves ("The activities here can still pass time for a bit.") unless an action has `hide` set.
- Every repeatable pastime in the first room follows one arc: first use shows a NEW toast with a line of
  philosophy; second use unlocks a note-finding action; third use unlocks an "exhaust" action. After it, the
  activity stays listed, greyed, with "not interesting anymore".
- Every era intro ends with "You have to pass time."
- Game time: era 0 is 1 game second per real second; later eras 3600x when idle.
- Hero poses: idle, walk, sit, read (profile sprite only), so furniture is turned and `seat()` overrides place him.

## The eras (index: name)

0 The Room, 1 The House, 2 The Decades, 3 The Centuries, 4 The Millennia, 5 Deep Time, 6 Stars, 7 The Long Dark,
8 Nothing. Their full content and links are in `docs/progression.png`. The notable recent shapes:

- **Room (0):** twelve-ish pastimes, each with the 1st/2nd/3rd-use arc. Exit "Step outside" after 40 days.
- **House (1):** widened house with a left window, a desk that faces the chair, a piano that starts under a dust
  sheet ("Take the sheet off" before you can learn it), a telescope found in the attic and aimed through the left
  window ("Watch the sky", 90 days, 3 uses), apples (3 waits), a garden (tool and almanac needed; "Plant and tend"
  is listed greyed with "I don't have the tool or the knowledge"), writing a book (3 steps) and the piano (3 steps)
  need the first room's books and records exhausted. Exit "Follow the road" (1 year in era, letters and telescope).
- **Decades (2):** a road with evenly spaced stops: milestone, painting workshop, easel, village, conservatory,
  university. "Walk across the world" takes a random 3 to 10 real seconds and the same number of game years, and
  each walk reveals one more place, in a random order saved per game, with the village always last. The conservatory
  is only ever found if the piano was learned in the House. When every place is found the walk greys out. The village
  has "Explore the village" then "Build a house with your hands" then the exit "Move into your house", which
  appears only once the house is built and needs nothing else.
- **Centuries (3):** old oak (raise a forest), telescope (chart the stars, 200 years), the village (watch it become
  a city, found in era 2), a stone table (follow one family, no prerequisites), the high hill exit.
- Later eras are unchanged for now.

## How the code is organised

- `godot/scripts/data.gd`: all content. `A()` action: `req`, `needs` (done N times), `soft` (listed greyed with a
  spoken reason), `lock_msgs`, `give`, `exhausts`, `min_years`, `hide` (not shown until flags are set), `max_uses`,
  `sec_range` (random real seconds, also used as game years), `once`, `search`, `lock`, `exit`. `H()` hotspot with an
  optional `show` flag list. `QUOTES` (one per action id), `NOTES`, `AUTO` (flags that follow from counts),
  `REVEALS` (places an action reveals one by one, shuffled once per save; entries may have `need` and `last`).
- `godot/scripts/main.gd`: state `S` (era, flags, notes, done, counts, exhausted, reveal, era_start, elapsed,
  ended, real), the action loop (`start_action`, `finish_action`), HUD drawing, save/load.
- `godot/scripts/scene_*.gd`: one 3D diorama per era (`scene_room`, `scene_house`, `scene_road`, `scene_summit`,
  `scene_observatory`, `scene_plateau`, `scene_space`, `scene_nothing`). Each implements `build()`, `update(ctx, dt)`
  and optionally `seat(ctx)`. `scene_base.gd` has `cam_off` (sideways framing).
- Building blocks: `mk.gd` (primitives, bottom-centre convention), `tex.gd` (procedural textures), `kit.gd`
  (outdoor props), `sky.gd`, `hero3d.gd` `sprites.gd` `painter.gd` (the hero), `synth.gd` (audio),
  `shaders/post.gdshader`.
- `godot/scripts/debug_tools.gd`: self-contained debug mode; deleting the file removes it.

## Gotchas that cost time before

- `quit()` inside `_initialize` hangs headless tests; quit from `_process`. Delete the save file before and after
  tests that could write it.
- Do not name a method `_set`/`_get` on an Object subclass (clashes with `Object`). Do not name a class `World3D`.
- Godot `:=` inference fails on Variants: use explicit types.
- Exporting `PassingTime.exe` fails if the exe is running ("cannot rename temp file"). Close the game first, or
  export under another name and rename.
- The exe icon looks wrong after replacing it until Windows rebuilds its icon cache; it is not a bad build.
- Shell heredocs with mixed quotes broke multi-line edits repeatedly; write small patch scripts to files.

## What is next (nothing is promised)

- **Era 4 (The Centuries) needs more activities.** Ideas that last centuries: raise a cathedral stone by stone,
  follow a river as it changes course, teach one language and watch it drift, breed a new rose or apple, keep a
  lighthouse, build a dry-stone wall across a country, age a cask of wine, walk a coastline as it erodes.
- The conservatory and university sit close together on the road; they could be narrowed.
- The village "Build a house" shows the finished house but there is no visible house in the era 4 valley.
- Eras 5 to 9 have not had the content and look pass that eras 1 to 3 got (more branches, richer buildings).
- `docs/progression.png` must be re-rendered by hand (see above) whenever content changes.
- The exe is not tracked: rebuild it from the project.
